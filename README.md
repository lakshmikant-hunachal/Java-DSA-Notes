# 🚀 Data Structures and Algorithms (DSA)

Welcome to my **DSA Repository!** 👋

This repository contains my learning journey and practice implementations of Data Structures and Algorithms using Java.

The main goal of this repository is to strengthen problem-solving skills, understand important DSA concepts, and prepare for coding interviews.

## 📚 Topics Covered

The repository is organized into different folders based on DSA topics.

- **Basics of Java** – Variables, Loops, Functions, Arrays
- **Arrays** – Searching, Sorting, Array Problems
- **Strings** – String Manipulation and Problems
- **Recursion** – Recursive Problems and Backtracking
- **Sorting Algorithms** – Bubble, Selection, Insertion, Merge Sort, Quick Sort
- **Searching Algorithms** – Linear Search, Binary Search
- **Linked List** – Singly, Doubly and Circular Linked List
- **Stacks** – Stack Implementation and Problems
- **Queues** – Queue, Circular Queue and Deque
- **Hashing** – HashMap, HashSet and Hashing Problems
- **Trees** – Binary Trees, BST and Tree Traversals
- **Heaps** – Priority Queue and Heap Operations
- **Graphs** – BFS, DFS, Dijkstra, Bellman-Ford, Prim's and Kruskal's Algorithms
- **Greedy Algorithms** – Greedy Techniques and Problems
- **Dynamic Programming** – Memoization, Tabulation and DP Problems
- **Backtracking** – N-Queens, Sudoku and Other Problems
- **Disjoint Set Union (DSU)** – Union-Find, Path Compression and Union by Rank
- **Bit Manipulation** – Bitwise Operators and Problems
